# Sepideh Tadayon Portfolio

Static HTML/CSS/JS landing page prepared for GitHub Pages.

## Publish
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.

## Before publishing
- Replace the placeholder LinkedIn `href="#"` with your real profile URL.
- Replace the CSS project mockups with real screenshots later if you want.
- The current site uses Google-hosted DM Sans and Caveat because no local font files were attached in this chat. If you provide your `.woff/.woff2` files, add them via `@font-face` in `style.css`.
